# 鹅腿阿姨事件：校园传播案例页面

[在线阅读](https://dev-belly.github.io/goose-leg-auntie-site/) · [页面源码](index.html) · [详细笔记](鹅腿阿姨事件_Skill蒸馏完整版.md)

这是一个纯静态中文案例页面，梳理校园圈层传播、社群运营、人物叙事及食品信息争议。页面底部列有新闻来源，区分了公开报道和从报道引出的运营分析。它是一份案例展示，**不是**对经营数据的独立审计、经验证的增长实验或法律结论。

## 查看和维护

直接在浏览器打开 `index.html` 即可查看；部署使用 GitHub Pages。无构建工具、外部 API 或用户数据收集。修改事实和时间线时，请同时核对页面底部的来源链接与发布时间；修改分析判断时，不应把推断写成已证实事实。

## 在作品集中的位置

该仓库展示的是信息组织与静态页面呈现。金融数据、审计和量化方向的技术项目集中在 [dev-belly 的项目入口](https://github.com/dev-belly)。
